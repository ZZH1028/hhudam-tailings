模型、结果和资料怎么导入

GitHub Pages 入口使用页面右下角的「原站业务」与「工程分析」切换工作区。原站业务继续使用原账号。若使用私密完整版，管理员从原站左栏进入「工程分析」，普通用户通过「功能菜单」进入模型和资料。

三维模型和视角

在「三维场景」切换原站实景、示例模型和已导入的模型，再点击总览、俯视、坝前或侧面。支持本地单文件 GLB、可跨域读取的 HTTPS tileset.json、GLB 或 glTF，以及你有权访问的 Cesium ion 资产。对局部模型输入真实的 WGS84 原点、高程和局部 x 轴逆时针旋转角。3D Tiles 通常使用其自身地理变换。

溃坝动画和点查

在「溃坝淹没」选择结果，点击「定位计算范围」，播放或拖动时间轴。点击地图或输入 WGS84 经纬度后可读出当前水深、全过程最大水深、首次超过 0.01 米的记录时刻和过程曲线。计算范围外和无有效网格的点单独标记。

内置矩形河槽结果是演示。可下载规则水深 JSON和规则水深 CSV核对导入格式。

OpenFOAM 结果

  1. 保留完整算例网格及时间目录。并行求解结果先重构。若导出多时刻 VTK，提供 PVD 时间索引及全部关联文件。
  2. 若有经过核对的水深字段，可直接按 JSON 或规则 CSV 生成网格。原始算例、VTK 或 PVD 可用OpenFOAM 转换工具转成 JSON。
  3. 在「溃坝淹没」选择文件或粘贴 HTTPS 文件直链，再确认数据和实景模型的坐标及高程基准。
python -m pip install -r requirements.txt
python openfoam_import.py results.zip depth.json --lon 118.754 --lat 32.045 --height 0

请将示例经纬度和原点高程换成你的工程值。VOF 体积分数转换得到的是等效水柱深度。已有实际水深字段时宜直接采用，并核对网格分辨率与高程基准。

专业资料与 AI

支持本地文件或可直接读取的 PDF、TXT、Markdown 地址。已入库手册可按术语检索，打开引文可以核对页码和片段。扫描件先 OCR 后再导入可以建立文字索引。勾选「使用原站 AI 组织回答」后，问题和命中的片段会发送至原站 AI 接口。接口响应异常时仍显示命中的片段。

网页内新增的模型、结果和资料保存在当前浏览器。不同设备和不同浏览器各自维护一份导入记录。
